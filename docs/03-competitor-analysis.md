# 03 — Competitor analysis: top 20 Arusha safari and trekking operators

Research carried out 26 October 2026. Everything here comes from pages that were actually loaded on that date; each section lists its URLs. Competitor wording is paraphrased; no text or images are reproduced.

## Method and limits (read this first)

| Item | What happened |
|---|---|
| Browser | Claude in Chrome was requested but its tools did not load in this session, so pages were read with a text fetcher (WebFetch) plus web search, as the brief allows. |
| What a text fetch can't see | Visual design, real mobile layout, and content rendered by JavaScript (some forms, review widgets). Where an item couldn't be seen it is marked **?**, not ❌. |
| SafariBookings | ✅ Used as the **primary ranking source**. Every rating, review count, founding year and office address was read from the operator's own profile page. |
| TripAdvisor | ❌ Every request returned **HTTP 403**, so no TripAdvisor numbers are used. Review counts that operators print on their own sites are not used for ranking (several sites contradict themselves, see below). |
| Google reviews | ❌ Not readable without a browser. Not used. |
| TATO membership | Checked against the TATO A–Z member pages at tatotz.org/portfolio-tags/{letter}/. The directory renders unevenly (page counts in titles don't match the listings shown), so "not found" means *not found in the pages that rendered*, not proof of non-membership. |
| Page speed | Google PageSpeed API returned HTTP 429 (rate-limited) for every site, so no speed scores are reported. |
| Coverage | 6–10 pages per company: homepage, listing, 2–3 itineraries, enquiry page, about/team. No forms were submitted. |

- **Strengths:** mid-range itineraries give per-day km, game-drive hours, a named lodge, meals and a route map image, plus a downloadable PDF. The product range is wide (camping, mid-range and luxury, migration, all Kilimanjaro routes, day trips). A newsletter capture appears on every page.

## Market patterns

### Table stakes: nearly everyone does this, so we must too
| Pattern | Seen in |
|---|---|
| Day-by-day itinerary | 18/20 |
| Zanzibar beach extension or combo | 17/20 |
| Tailor-made enquiry form | 16/20 |
| Blog | 16/20 |
| WhatsApp contact | 13/20 |
| Lodge named for each night | 13/20 |
| Inclusions and exclusions list | 12/20 |
| Enquiry-only booking (no online booking for safaris) | 20/20 |
| Review-site logos (TripAdvisor / SafariBookings / Google) | most, but usually static images, not live counts |

### Differentiators: only the best do this
| Pattern | Who does it well | Why it matters |
|---|---|---|
| **Price grid by group size and season** | Altezza, Lion King, Zohar, Zara | Answers "what will it cost *us*?" without an email exchange; only 4/20 do it |
| **Published deposit and cancellation terms** | Easy Travel, Duma Explorer, Zara, Nkollo, Kojuu | Lowers perceived risk before the first contact |
| **Online deposit payment** | Altezza (Kilimanjaro, $100 by card) | The only path from browsing to committed booking without email |
| **Kilimanjaro success rate per route** | Altezza (by route and days); Duma Explorer (industry averages) | The no. 1 question climbers ask |
| **Fixed-date group departures board** | Zara | Converts solo travellers and price-sensitive climbers |
| **Guided "design my safari" wizard** | Soul of Tanzania | Better-qualified leads than a free-text box |
| **Listing filters** (style, season, circuit, budget) | Shadows of Africa, Kla (price slider), Ozon, Soul of Tanzania | Discovery across 30–200 trips |
| **Currency switcher incl. TZS** | Ozon Light; Altezza (USD/EUR/GBP) | European buyers think in EUR/GBP |
| **Sustainability credentials** (KPAP, Travelife, B Corp) | Altezza, Easy Travel, Duma Explorer | A decision factor for European and US travellers, especially for Kilimanjaro porter welfare |
| **Lodge options per comfort tier** | Altezza, Lion King | One itinerary sells to three budgets |
| **Client portal after booking** | Altezza | Collects passport, diet and insurance data without email chains |

### Gaps nobody fills well: our opportunity
| Gap | Evidence | Opportunity for Safara Africa |
|---|---|---|
| **No mobile-money payment** | 0/20 mention M-Pesa, Tigo Pesa or Airtel Money. Card payments go through Pesapal, DPO or Stripe. | Accept mobile money (via a Tanzanian aggregator) for East African residents and for local agents. It's also the cheapest way for the diaspora to pay deposits. |
| **No online booking for safaris** | 0/20. Altezza takes a deposit online only for Kilimanjaro. | Request quote → accept → **pay deposit online** for any itinerary. |
| **No trip builder with a live price** | 0/20 (Soul of Tanzania has a wizard but no price) | A safari builder (parks × days × lodge level × group size → instant estimate) would be unique in Arusha. |
| **Park fees are a black box** | No operator shows the TANAPA/NCAA fee breakdown inside its price | A transparent price breakdown (park fees vs lodging vs vehicle) builds trust and explains price differences. Keep it as data so it can be updated yearly. |
| **No altitude profile charts** | 0/20; altitudes appear only as text | A simple altitude-by-day chart per Kilimanjaro route, plus success rates by route length. |
| **No licence number shown** | 0/20 show a TALA licence number. TATO badges are logos only. | Show the TALA licence number and TATO membership with a link to verify. |
| **Content quality is poor everywhere** | 20/20 had at least one visible error: stale 2023–2025 prices, mismatched day counts, placeholder contacts, server errors, broken CTAs | A clean, fact-checked site with dated, reviewed itineraries and **prices tied to a date range** is itself a differentiator. Build in validation so content can't drift. |
| **Prices out of date** | Lion King, Zohar and Shadows display past-season prices or departures | Prices kept in data with `validFrom`/`validTo`, expired rows hidden automatically. |
| **Review counts contradict each other** | Easy Travel, Zara and Altezza show different counts on different pages | One source of truth for review stats, shown with a date. |
| **Filters by month or park** | No site filters by travel month or park together | Filters for month (tied to migration timing), park, length, budget and style. |

## What this means for Safara Africa (inputs to Phase 4)

1. **Close the table-stakes gaps first.** Day-by-day itineraries, a lodge per night, inclusions and exclusions, WhatsApp with context, and real reviews are what nearly every competitor already has. The current site has none of the itinerary detail.
2. **Copy the top-three differentiators that fit our size:** the price grid by group size and season, published deposit and cancellation terms, and listing filters.
3. **Own two gaps no competitor has filled:** a transparent price breakdown with park fees kept as yearly data, and an online deposit path that includes mobile money.
4. **Make content correctness a feature:** dated prices, build-time validation, no placeholder text.
